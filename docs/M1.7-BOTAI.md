# M1.7 — optional BotAI integration

LuCa can use BotAI v1 through a native C adapter. BotAI remains optional at
both build time and runtime.

Configuration:

```ini
botai_url=http://botai:8090
botai_expert=auto
botai_timeout_seconds=30
```

When `botai_url` is absent LuCa does not initialize BotAI. When configured,
LuCa checks `/v1/version` and enables `!ai <message>` only for compatible
BotAI v1 services. Connection, timeout or compatibility failure disables AI
without preventing normal IRC or Lua operation.

The HTTP adapter uses libcurl when available. CMake does not require libcurl,
so a LuCa build without it remains a fully functional IRC bot; BotAI simply
cannot be enabled in that build.

M1.7 is intentionally stateless. Bounded caller-owned conversation context,
natural conversation and PBMP `botai.status` are later LuCa milestones.
