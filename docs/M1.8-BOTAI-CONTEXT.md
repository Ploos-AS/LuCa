# M1.8 — bounded BotAI conversation

LuCa now owns optional, bounded BotAI conversation context. BotAI remains
stateless: LuCa sends the selected history with each request.

Configuration:

```ini
botai_history_messages=10
botai_conversation=false
```

History is memory-only and limited to 0–20 messages. Odd limits are rounded
down so complete user/assistant exchanges are retained. A failed BotAI request
is not added to history. `!aireset` clears the current session context.

Natural conversation is opt-in. When enabled, ordinary private messages and
explicit channel addressing such as `LuCa: hello` can invoke BotAI. Messages
starting with `!` remain commands and are not treated as natural prompts.

M1.8 deliberately uses one session-local history store. Per-channel/per-user
scope isolation is deferred to the next milestone so the first native-C history
implementation remains small and auditable.
