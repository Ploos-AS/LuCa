# M1.9 — isolated BotAI conversation scopes

LuCa isolates BotAI history by IRC conversation:

- channel messages use `channel:<channel>`;
- private messages use `nick:<sender>`.

`!aireset` clears only the current conversation scope.

The scope table is bounded to 32 entries. When full, the least recently used
scope is replaced. Each scope retains the M1.8 bounded history limit of at most
20 messages, so neither conversation length nor the number of retained
conversations can grow without bound.

Scopes are session-local and memory-only. They are discarded when LuCa exits.
No conversation content is persisted or exposed through PBMP.
